# Mega Ótica — site institucional

Projeto estático e responsivo feito a partir das informações das imagens `frente.jpg` e `tras.jpg`.

## Abrir o site

Abra esta pasta no Visual Studio Code e abra `index.html` no navegador. O site não precisa de instalação ou compilação.

## Arquivos

- `index.html` — conteúdo e estrutura da página.
- `styles.css` — identidade visual e layout para computador e celular.
- `script.js` — menu móvel, filtros da coleção e ano do rodapé.
- `frente.jpg` e `tras.jpg` — imagens de referência fornecidas.
